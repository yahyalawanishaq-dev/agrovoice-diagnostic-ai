# 🐟 AgroVoice AI — Condition Diagnostic Engine

AgroVoice is a practical diagnostic advisory engine designed to help smallholder farmers and aquaculture operators rapidly identify health risks in fish ponds and livestock pens.

---

## 🎯 Problem Statement
Rural aquaculture and livestock producers face sudden mortality events from rapid water deterioration (such as dissolved oxygen depletion) and contagious infections without immediate access to veterinary specialists. AgroVoice provides an instant first-line diagnostic assessment.

---

## 🚀 Key Features
* **Aquaculture Monitoring**: Diagnoses gasping, erratic swimming, and appetite loss linked to DO crashes, ammonia toxicity, or parasites.
* **Livestock Advisory**: Evaluates physical and behavioral symptoms in poultry (e.g., coccidiosis, brooder stress).
* **Extensible Architecture**: Structured rule engine built in Python, designed for integration with local-language voice models (Whisper/IVR pipelines).
